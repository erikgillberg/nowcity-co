Why It Exists

Born from an inconvenient number

During the Edgewater feasibility work, the honest math delivered a hard truth: at real, market-anchored Salem rents, a conventional building on a conventional cost basis loses money. A naive reading says the district is infeasible. That reading is wrong, and it is exactly the conclusion that has kept corridors like this one undeveloped for decades.

Capable teams close gaps like this every day, using real tools: industrialized construction, more efficient building types, public gap financing, tax-credit equity, patient agency debt, placemaking, energy income. But those moves are usually invisible to the investors, public partners, and communities whose yes a project needs. The Upside Explorer was built to make the case transparent: one place, every move named, every number defensible, open to interrogation by anyone.

Start From the Honest Floor

The base case earns nothing it cannot cite. Rents are grounded to achieved Salem comps, and the floor is allowed to be negative. Credibility comes first.

Every Lever Is Real

No fudge factors. Each lever corresponds to a tool experienced teams actually use, underwritten at the value we are willing to defend, never a claimed maximum.

Show the Build-Up

A waterfall attributes the climb from floor to final return, category by category, so the result is legible rather than asserted.

How It Works

Four steps from floor to proof

Ground the Base Case

A conventional double-loaded building at achieved Salem rents, grounded to named comps. No aspiration, no premium: the deal as a merchant developer would actually build it.

Stack the Levers

50+ separable levers across building type, cost and delivery, revenue and placemaking, public tools, affordable-housing finance, and capital structure. Each carries a plain-language explanation and a single defensible number.

Read the Waterfall

The build-up from the floor to institutional returns is decomposed by category, so you can see exactly which moves carry the project and challenge any of them.

Interrogate Everything

Worked scenarios run from the honest floor to the full regenerative stack. It is the same live engine we underwrite with, not a PDF: change an assumption and watch the district answer.
